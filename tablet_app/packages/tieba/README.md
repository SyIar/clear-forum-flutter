# Tieba package provenance

Vendored from `https://github.com/SyIar/tieba-lite-flutter` revision
`ab3926ea07e39ca6f44f2d4d79c53919ba5cefbd`.

The original `LICENSE` is retained. Generated protocol files retain their source headers.
This package preserves the existing Tieba transport, login, account, posting and reading features.

Local adaptation:
- Material 3 appearance on Android.
- Rail/bottom navigation selected by window width.
- `TabletThreadHost` provides a persistent directory/reader split.
- `TabletBridge` injects the host application's private download manager.
- iOS project, platform packaging and large optional font files are not vendored.

Dedicated localization files are authorized resources for this personal application.
