# Compact media previews and unified reader controls

- Embedded Turbo and other video providers share one 150-by-84-point preview card. The play glyph is centered over a translucent circular scrim; the whole card opens the player. The separate right-hand control is removed. Preview resolution and image caching remain shared, and the loading spinner sits in a corner until the image request completes. The fixed dimensions preserve the reader's scroll layout.
- Reader toolbar buttons and menus share a 22-point Pika icon canvas inside a 44-point touch target. This removes layout differences between text-label buttons and bare menu images while retaining the system's toolbar grouping. The same sizing is used by the download drawer's controls.
- The download drawer uses the upstream Pika `pause-big`, `play-big` and `clean-broom` assets from the existing pinned ChunUI revision. The old small glyphs left excessive whitespace inside the pause/play canvases.
- The broom invokes the existing completed-task cleanup. It removes saved/finished and cancelled/stopped download records. Active, paused and failed/retryable tasks remain. Saved Photos assets and files in the Gofile/hosted download directories are retained. The button is disabled when no records qualify.
- The reader's bottom-left pager is collapsed to a Pika page-navigation icon. It opens a centered horizontal capsule containing previous page, the current page and next page. The page label opens the existing page picker. The bottom-right controls open top, bottom and refresh at exactly the same position.
- Both panels share a 248-by-56-point glass capsule, equal action columns, 22-point icons and vertical separators. An optional panel state makes the two menus mutually exclusive. Repeated taps close the current menu; switching triggers replaces its contents. Scrolling, navigation, purchases and explicit reloads close the panel. An overlay avoids changing reader height or scroll position. Reduced Motion disables the slide animation.
- Bookhouse uses the same action capsule and, for its numbered search results, the same pagination control and page picker. Its cursor-based catalog continues using the existing load-more behavior.

Local Swift syntax, localization, repository-policy and icon-resource checks passed. No simulator is used. Physical-device spacing, preview cropping and toolbar appearance require user acceptance.
