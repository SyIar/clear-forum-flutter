## Validation

- `scripts/check_swift_syntax.py`: tree-sitter syntax only; not Swift type checking
- `scripts/check_repository.py`: repository policy and credential patterns
- `scripts/check_media_probe.mjs`: source observation, provider isolation, bounded autoplay
- `scripts/gofile_bridge.test.mjs`: existing nine Gofile bridge cases
- Core regression tests cover redirect/search/title safety, bookmark destinations, South metadata/pagination and free-purchase recovery
- `.github/workflows/ios-validate.yml`: manually triggered Swift core tests, media checks and Debug simulator compilation. No packaging, release, deployment, signing credentials or IPA output

All requested HTML examples were inspected as inert text outside the repository. The South directory declares 10,342 pages, and the picker now uses direct numeric entry plus at most 13 nearby/boundary choices. The directory sample itself already used supported page links, so the precise original all-gray state is not proven; its control enabling and large-range handling were revised.

Apple compilation, Swift test execution and device acceptance remain unrun. At the user's latest request this branch is source-only delivery for the user to build; there is no automatic validation or packaging trigger.

7. Test multiple zero-SP offers mixed with paid offers, price changes, a persistent per-offer lock, lost responses and blocked authors. No positive-price automatic purchase
8. Check directory creation date/count against source rows and page selector on first/middle/last South pages
